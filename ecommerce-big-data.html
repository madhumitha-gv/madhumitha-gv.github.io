E-Commerce Big Data Analytics

A cloud pipeline from raw files to model and dashboard

Raw Amazon sales files were too large to query directly or model against. This pipeline lands them in S3, transforms them with PySpark on EC2, and feeds the processed output to both automated model training and a revenue dashboard.

RoleSole developer
PlatformAWS
ProcessingPySpark on EC2
OutputsSageMaker AutoML, Power BI

The pipeline

  1. Raw data in S3. Source sales files land in object storage, cheap to hold and straightforward to version.
  2. Transformation on EC2 with PySpark. Cleaning and reshaping run distributed, so the job scales with data volume rather than being bounded by one machine's memory.
  3. Processed data back to S3, which becomes the single input both downstream consumers read from.
  4. Two consumers: SageMaker AutoML for model training, and a Power BI revenue dashboard for reporting.

Why it is shaped this way

Writing the processed data back to S3, rather than passing it straight into training, means the modeling and reporting paths stay independent. The dashboard does not wait on a training run, and retraining does not require re-running the transformation. It also makes the processed layer reusable for any later consumer.

Scope

This is an infrastructure project rather than a modeling one. The work is the pipeline — the storage layout, the distributed transformation and the handoff to two different consumers. Model selection was delegated to SageMaker AutoML by design.

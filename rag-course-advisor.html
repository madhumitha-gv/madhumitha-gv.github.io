RAG Course Advisor Chatbot

Hybrid retrieval over ten graduate program handbooks

Graduate students at IU Luddy were digging through ten separate program handbooks to answer one question. This chatbot fuses lexical and semantic retrieval so an exact course code and a vaguely worded question about electives both resolve, and answers with citations back to the source handbook.

Corpus10 handbooks, 8 programs
RetrievalBM25 + FAISS, reciprocal rank fusion
StackPython, Mistral, Streamlit

The problem

Luddy publishes separate handbooks for Computer Science, Data Science (residential and online), HCI Design, Informatics, Information and Library Science, Intelligent Systems Engineering and Secure Computing. Answering one advising question often means knowing which of ten PDFs to open and where to look inside it.

Why one retriever is not enough

The query spectrum has two ends and neither retriever covers both.

  • BM25 excels at exact matches. A student searching DSCI-D590 needs lexical precision, and BM25 finds that exact code.
  • FAISS captures meaning. A question about "machine learning electives" should also surface courses described as "predictive modeling" or "statistical learning", even when none of those words appear in the query.

Reciprocal rank fusion merges the two ranked lists using ranks rather than scores. That matters: BM25 scores and cosine similarities live on completely different scales, so fusing on raw scores requires a normalisation step that rank-based fusion avoids entirely.

Build

  • Extraction: pdfplumber, chosen because it preserves the tables and structured layouts that academic handbooks are full of.
  • Chunking: section-based with a size fallback, so a handbook section stays semantically coherent rather than being cut at an arbitrary token count.
  • Embeddings: all-MiniLM-L6-v2, 80MB and CPU-friendly, with strong short-text retrieval performance.
  • Vector search: FAISS IndexFlatIP, selected for raw score access, which the fusion step needs.
  • Generation: Mistral Small, for instruction-following on grounded, context-only question answering.
  • Interface: Streamlit chat with expandable source citations, so every answer can be traced to the handbook it came from.

Why citations were non-negotiable

An advising answer that is confidently wrong is worse than no answer, because a student may act on it when choosing courses. Grounding generation strictly in retrieved context and surfacing the source passage alongside every response makes the system checkable rather than merely fluent.

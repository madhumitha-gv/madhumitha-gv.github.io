Recent side projects

Human Reference Atlas Usage Analytics

The HRA dashboard reported traffic volumes but told its developers nothing about how researchers actually move through the registration and exploration interfaces. I pulled 250,853 Google Analytics events through BigQuery, cleaned them down to the 50,000 that carried real interaction signal, and mapped them with an hourly click heatmap, a Sankey of event-to-event transitions and a treemap, showing that placement and node selection dominate the workflow while filters such as sex and side go almost unused, which gave the UX team a concrete discoverability gap to close.

250,853 events analyzed Google Analytics, BigQuery, Pandas, PM4Py, Plotly View project

RAG Course Advisor Chatbot

Graduate students at IU Luddy were digging through ten separate program handbooks to answer one question about a course code or an elective. I built a chatbot that fuses BM25 and FAISS retrieval through reciprocal rank fusion, so exact codes and vaguely worded questions both resolve, and Mistral answers with citations back to the source handbook.

Ten handbooks across eight programs FAISS, BM25, Mistral, Streamlit View on GitHub

Multi-Agent Travel Discovery Planner

Every travel planner asks you to choose a destination first, which is the hardest part when you only know the kind of trip you want. I built six LangGraph agents that infer a persona from free text, rank 500 cities by embedding similarity and gate on live weather, walking the shortlist until a city passes, and deployed it on Azure Container Apps.

500 cities checked in ~1.6s LangGraph, DeBERTa-v3, Mistral-7B, Azure View on GitHub Live demo

Document Processing Pipeline

Scanned documents arrive blurred, stained and creased, and standard OCR fails on all of it. In 24 hours at IU Hackathon 2026 I built a U-Net that denoises the page to 43 dB PSNR, TrOCR that reads it at 90% character accuracy, and an adaptive Huffman encoder written from scratch that recovers the text losslessly on every run.

43 dB peak PSNR, 100% lossless PyTorch, U-Net, TrOCR, FastAPI, React View on GitHub Demo video

Workplace Mental Health Risk Prediction

Employers catch mental health risk late, through questionnaires and interviews that miss the early signals. I modeled 1,467 tech-industry survey responses with composite indices for employer support, workplace stigma and organizational openness, reached 0.83 F1, and served the result through a Streamlit app and FastAPI backend where SHAP explains every individual score.

0.83 F1, ~85% accuracy XGBoost, SHAP, FastAPI, Streamlit View on GitHub

E-Commerce Big Data Analytics

Raw Amazon sales files were too large to query directly or model against. I built an AWS pipeline that lands the data in S3, transforms it with PySpark on EC2, and feeds the processed output to both SageMaker AutoML training and a Power BI revenue dashboard.

AWS, PySpark, SageMaker, Power BI View on GitHub
